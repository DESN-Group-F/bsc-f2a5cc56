# Backlog status

The LP, T and CR files preserve historical planning and run evidence. They are not the current team queue, automatic assignments or project-wide acceptance gates.

Use [the team guide](../docs/TEAM_PROJECT_GUIDE.md) and [project instructions](../AGENTS.md) for current responsibilities and task scope. Start from [PROJECT_START.md](../PROJECT_START.md).

Do not automatically resume LP04 or another stale task from its recorded status. The owner of an assigned task can select and adapt relevant earlier work. Preserve frozen CR run records and task cards as evidence rather than rewriting them as current instructions.
