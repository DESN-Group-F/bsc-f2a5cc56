## Frozen behavior

Teaching groups remain private, fixed selections. A teacher can review a temporary actual checkout when a member is unavailable, without changing its group definition, responsible owner or registered home. Strict automatic alternatives require the same known model and specifications, prefer verified registered rooms with more available stock and cannot reuse a battery. Unknown specifications and unverified rooms are never inferred. Recommendations do not reserve stock.

Manual alternatives use the shared inventory Filter and can be selected outside the fixed group within the same inventory, existing borrowing authority and fixed personal scope. Different or unknown model/specification evidence is clearly labelled for the teacher's explicit review. Clearing filters retains selected mappings. Exact registered-tag input and platform NFC evidence use the same staged alternative workflow, with explicit source changes and original member selection. The browser states its native-reader limitation; manual text input is never labelled a hardware read.

Saved actual checkouts retain the original group/version/member evidence, original-to-actual mapping, selection source, reviewed asset/tag/version bindings, native actor, time and real Loan IDs. Complete and partial returns use those actual loans. Atomic native authority, inventory/personal/group bounds, versions, tags, active loans and request reservations guard writes. Conflicts require another review; an uncertain result retries only its captured original request. Shared Activity, complete exports and authorized permanent deletion maintain the corresponding structured evidence boundaries. Independent Task definitions and private group maintenance remain separate.

Battery details include service age, complete non-voided borrowing usage and dated inspections. Missing manufacture age, duration and specifications remain unknown. Staff record inspections; administrators retain reasoned corrections. Staff and administrators can review eligible retirement/recovery, while permanent deletion of Scrapped records requires administrator authority and a separate guarded confirmation.

New-registration reminders use attributable first server registration, account-specific acknowledgement and a 48-hour lifetime. Filtering, returns, recovery and metadata edits do not restart registration time. Idle/focus refresh remains eventual polling. The theme, stock labels, sidebar collapse control, spacing, disclosure/navigation motion and download feedback are consolidated; list animation observers ignore unrelated portal/tooltip changes and retain legitimate list reorder motion.
