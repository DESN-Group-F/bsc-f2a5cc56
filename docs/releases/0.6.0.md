## Frozen scope

The application separates workspace composition, navigation, client requests, recovery, inventory services and shared visual tokens into named modules. Existing staff authority, account/dataset boundaries, exact loan and version guards, complete exports and immutable evidence remain required. The yellow-and-ink visual system covers inventory, workstations, tasks, dialogs and sign-in, with larger operational text, darker supporting text and an explicit light theme.

Messages has Inbox and Removed views, recoverable personal removal, explicit task completion and saved-completion actions, and clear assignment or removed-plan explanations. Reading a message remains independent from completing its shared task. Administrators may remove and restore shared recurring plans; removal stops new task/reminder generation and blocks pending completion while preserving configuration state, original cycles, deadlines, messages and completion history. Restoration reuses those records. Removal/restoration requests preserve their original identity in account/dataset-specific tab storage before sending and support explicit recovery after interrupted results.

This freeze retains the preceding snapshot's model-assisted registration, reviewed demonstration intake, optional-reason retirement/removal, manual scan selection, grouped filters and English date/time controls. Teaching groups remains a private account/dataset workspace over shared assets, with fixed group views, reviewed battery operations, original member evidence and complete downloads. See the [preceding snapshot](2026-10-03-teaching-groups.md) and [requirements](../requirements.md) for the retained scope.

## Installation and limits

An existing 0.5.0 deployment requires unapplied migrations through 0015 before running this version. A deployment already at the teaching-groups snapshot requires 0015. Apply each migration only once in journal order and preserve a database backup; source publication does not apply migrations to any hosted database. Local startup instructions are in the [README](../../README.md).

Real RFID hardware, verified reader-to-room mapping, school SSO, JAGGAER, safety agents, unattended scheduling and outgoing email remain unavailable or unverified. Task evaluation occurs during authenticated use. Saved email preferences do not send mail, and task completion is not a safety certification. Full accessibility compliance, large-load capacity and measured staff-efficiency gains have not been established. Existing build chunk-size/plugin-timing warnings remain documented.
