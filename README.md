# Battery Inventory NFC functional test source

This standalone snapshot contains **Test 0.1.0**, an internal diagnostic prototype excluded from formal product releases. It does not change the main application's release version. No Git history, backend, business database, installed dependency tree or signed application is included.

## Local preparation

Use Node.js 22.13 or newer. From this snapshot directory:

```powershell
cd mobile
npm ci
npm test
npm run test:plugin
npm run build
node ../scripts/prepare-mobile-native.mjs --all
npm run dev
```

The native projects are included, but web assets and native plugin metadata must be regenerated by build and sync. A web build or project check does not prove native compilation or NFC operation. Android control-flow tests require a JDK and explicitly skip if it is unavailable.

The active `codemagic.yaml` contains only manual unsigned iOS verification and Android debug packaging. No workflow has been run by exporting this source. An unsigned iOS artifact cannot be installed on an iPhone. The separate `templates/testflight-workflow.yaml` is an inactive reference, requiring reviewed signing inputs and explicit test-distribution authorization before it is intentionally enabled. Repository publication, account actions, cloud builds and uploads are separate actions.

Optional inventory lookup requires a separately prepared, authorized HTTPS test backend. The backend and diagnostic web route are not in this snapshot; existing hosted endpoints are not assumed to contain them. Physical-read evidence remains separate from database identifier resolution.
